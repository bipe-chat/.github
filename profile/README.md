# Bipe

Bipe is a Brazilian messenger. Your data stays on servers in Brazil. It is free, has no ads and warns you about scams. It is built on [Matrix](https://matrix.org/) and forks [Element X](https://element.io/).

Site: [bipe.chat](https://bipe.chat)
