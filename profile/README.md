# Proseio

Proseio is a Brazilian messenger: free, without ads, with servers in Brazil and protection against scams. It is built on [Matrix](https://matrix.org/) and forks [Element X](https://element.io/).

Site: [proseio.com.br](https://proseio.com.br)
