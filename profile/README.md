# Bipe

Bipe is a Brazilian messenger. Your data stays on servers in Brazil. It is free, has no ads and warns you about scams. It is built on [Matrix](https://matrix.org/).

Site: [bipe.chat](https://bipe.chat)

## The app

| Repo | What it is | Licence |
|---|---|---|
| [bipe-app](https://github.com/bipe-chat/bipe-app) | Bipe for iPhone and Android, on matrix-rust-sdk | AGPL-3.0, with an app store permission |
| [bipe-shared](https://github.com/bipe-chat/bipe-shared) | Rules, texts, API contract and test vectors that the app, the API and the site share | AGPL-3.0 |
