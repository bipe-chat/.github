# Contributing to Proseio

Thank you for helping. This file applies to every repo in the Proseio organisation. A repo can add its own rules on top.

## Before you start

- For anything bigger than a small fix, open an issue first. Say what you want to change and why. Proseio keeps a small core on purpose, so some good ideas will wait.
- In the app forks (proseio-ios, proseio-android), Proseio code lives in its own module and Element's code gets small hooks only. A fix to Element's code belongs upstream at [element-hq](https://github.com/element-hq) first.
- Each repo has an `AGENTS.md` with its commands, rules and build gate. Read it before you open a pull request.

## Sign off your commits (DCO)

Proseio uses the [Developer Certificate of Origin](https://developercertificate.org/). Each commit must end with a sign-off line:

```
Signed-off-by: Your Name <you@example.com>
```

`git commit -s` adds it. The line says that you wrote the change, or have the right to submit it, under the repo's licence. There is no separate agreement to sign.
